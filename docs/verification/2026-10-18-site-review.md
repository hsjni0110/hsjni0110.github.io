# 포트폴리오 로컬 구현 검증 기록

확인일: 2026-10-18 (Asia/Seoul)

## 결과와 실행 방법

메인, 상세 사례 5개, 404 페이지와 이력서 PDF를 구현했습니다. 로컬 미리보기는 `npm run dev -- --port 4322`, 주소는 `http://127.0.0.1:4322/`입니다. 정적 결과는 `dist/`입니다.

공개 배포·호스팅 등록·원격 저장소 생성·푸시는 수행하지 않았습니다. `feat/portfolio` 로컬 브랜치와 작업 폴더를 유지합니다.

- `npm run check`: Astro/TypeScript 오류·경고·힌트 0건.
- `npm run build`: 메인·상세 5개·404의 정적 HTML 7개 생성.
- `node scripts/check-output.mjs`: 149개 로컬 참조, 이미지·서체 경로, 공개 출력 파일 유형, 승인 PDF SHA-256 일치, 본문 언어와 공개 범위 확인.
- Playwright Chromium: 전체 24개 통과. 루트와 `/portfolio/` 하위 경로에서 각각 확인.
- `SITE_URL=https://example.invalid BASE_PATH=/portfolio/` 시험 출력에서 canonical·OG·sitemap·robots와 base 경로 확인. 이후 기본 로컬 출력을 재생성해 시험 주소를 제거.
- 실제 브라우저의 360·390·768·1440px 가로 넘침 검사, JS 비활성 탐색, 키보드·포커스, 동작 줄이기, 이미지 실패, PDF·폰트·이미지 로딩 확인.
- 200% CSS zoom 상태의 읽기·연락 경로 검사. 브라우저 메뉴의 실제 확대 및 실제 보조공학 검증과는 구분함.
- 데스크톱 1440×1000, 모바일 390×844 실제 캡처에서 한글 줄바꿈·여백·사진·문서 읽기·화면 자료를 확인. 비공개 앱 이미지나 모집 링크 없음.
- 본문 색 #1D1D1F와 보조 #525A65, 링크 #005FCC는 밝은 바탕에서 대비를 확인. 모바일 주요 메뉴는 가로·세로 최소 44px로 회귀 검사.

## 테스트 우선 구현 기록

- 상세 페이지 구현 전 다섯 경로가 404인 실패를 확인한 후 구현하여 통과.
- 메인 제목·프로젝트 순서 검사는 기존 이름만 있는 화면에서 실패 후 통과. 접근성 텍스트의 공백 누락도 발견해 수정.
- 404 복귀 링크 부재를 확인한 후 구현하여 통과.
- 최종 검토의 요약 의미 구조, 큰 이미지 링크, 개선 전 화면, 모바일 클릭 영역 검사는 수정 전 네 건 모두 실패한 뒤 수정하여 통과.
- 고정된 문안·사진에는 구현을 복제하는 단위 테스트를 만들지 않고 직접 검수. 자동 검사는 공개 범위·사용자 탐색에 집중.

## 최종 독립 검토와 보완

구현과 분리된 읽기 전용 리뷰에서 중요한 결함으로 이미지 원본 열기 누락을 확인했습니다. 작은 문서 의미 구조와 개선 전 화면 누락도 사용자 요구의 완결성과 관련돼 이번 수정 범위에 포함했습니다.

수정 내용:

1. Figure와 상세 이미지마다 승인된 큰 화면 파일로 이동하는 링크 추가.
2. 상세 요약을 유효한 `dl`·`dt`·`dd`로 변경.
3. ForgeSync 기존 PDF의 개선 전 화면과 변경 이유를 실제 이미지·캡션으로 추가.
4. 직접 측정한 모바일 네비게이션의 작은 클릭 영역을 최소 44px로 확장.

큰 화면 링크가 추가되며 기존 테스트의 “캡션 링크가 하나”라는 전제가 깨진 것은 링크 역할을 구분하도록 수정했습니다. 근거 링크 존재·주소에 대한 단언은 유지합니다.

## 계획 실행 중 결정

- 새 저장소에 승인된 feature 브랜치를 생성했고 별도 worktree는 추가하지 않았습니다. 기존 개발 흐름이 없는 새 프로젝트이므로 사용자 지정 작업 폴더를 유지했습니다.
- 현재 안정 버전 Astro 7.4.0·TypeScript 6.0.3을 lockfile에 고정했습니다. Zod는 해당 버전 권장 `astro/zod` 경로를 사용합니다.
- Astro가 에이전트 실행에서 미리보기를 자동 분리해 테스트 프로세스가 종료되는 동작을 소스로 확인했습니다. `--ignore-lock`으로 소유한 로컬 서버를 foreground로 유지합니다. 시스템 설정 쓰기를 피하기 위해 telemetry를 비활성화했습니다.
- 서체는 public 대신 src/assets에 두어 빌드가 해시와 하위 경로를 처리하도록 했습니다. 라이선스는 공개 파일에 포함했습니다.
- SpeakText는 실제 편집 캡처 미확보로 제품 화면을 만들지 않았습니다. 판단의 흐름을 설명하는 글 도식과 코드·PR 링크를 제공합니다.
- 의미 구조와 개선 전후 증거 누락은 계획 완료에 영향을 주므로 검토의 작은 항목도 이번 회귀 수정에 포함했습니다.
- 사용자 요청에 따라 로컬 서버와 브랜치를 유지합니다. 승인되지 않은 병합·푸시·배포·도메인 연결은 하지 않습니다.

## 아직 검증하지 않은 범위

- 실제 호스팅의 없는 경로 HTTP 상태·캐시·외부 공유 미리보기.
- Safari·Firefox와 실제 보조공학, 브라우저 UI의 실제 200% 확대.
- 실제 현장 사용성·불량 탐지 정확도, 현재 앱 변경 버전의 사용자 효과, 원래 프로젝트의 성능. 이 사이트 제작으로 새로운 근거를 확보한 것은 아닙니다.
- 공개 GitHub·Velog가 앞으로 계속 접근 가능한지는 보장하지 않습니다. 읽지 못한 Velog 글 요약도 만들지 않았습니다.
- HINT 교육 상태는 2026.10 기준으로 명시했습니다. 실제 외부 공개 시 다시 확인해야 합니다.

이번 최종 검토에서 남겨둔 코드 수정 항목은 없습니다. 위 미검증 범위는 로컬 제작의 확인 한계로 남깁니다.
