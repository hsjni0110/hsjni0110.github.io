# 일러스트 중심 첫 화면

사용자가 선택한 두 번째 프로필 일러스트를 배치하고 전자기기 패널을 제거. 밝은 청록 배경, 남색 글자, 사선 패턴과 큰 인물 그림으로 구성. 인물의 hover 회전·이동은 동작 감소 설정에서 비활성화. 모바일은 소개→그림→작업 링크 순서. 생성 PNG를 프로젝트에 보관하고 Astro가 해상도별 WebP로 제공.

Astro 검사 오류·경고 없음. 최종 정적 빌드 및 로컬 참조 118개 검사 통과. 브라우저 테스트 29개 통과. 데스크톱과 390px 모바일 직접 확인 및 PNG 저장. 전자기기 전용 테스트는 해당 UI 제거와 함께 제거하고 실제 작업 링크 테스트 유지. PDF와 상세 페이지 내용은 이번 변경 범위 밖. 공개 배포 없음.
