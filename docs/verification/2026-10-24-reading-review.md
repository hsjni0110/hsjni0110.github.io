# 일러스트 사이트 읽기 점검

메인 첫 화면·프로젝트·Writing·소개 펼침·연락과 네 상세 사례를 실제 브라우저로 점검. 360px 모바일에서 ForgeSync의 실제 화면이 긴 설명 뒤로 밀리는 점, SpeakText 도식이 본문의 추상적인 단계만 반복하는 점, 기울임과 본문 진입 이동이 읽기에 불필요한 점을 확인.

- 모바일의 프로젝트 도해/실제 화면을 설명 앞에 배치.
- SpeakText의 추상 단계 도식을 발화자 A/B 색 구분, 선택된 대사 2개, B→A 일괄 변경을 보여주는 정적인 설명용 예시로 교체. 실제 화면이나 인터랙티브 편집기로 오인하지 않도록 명시.
- 도해와 Writing 카드의 회전 제거. 본문 진입은 14px 이동·420ms에서 위치 이동 없는 180ms 명도 전환으로 축소. 터치 환경의 hover 잔류 방지.
- 상세 제목에 균형 줄바꿈 적용. 원문과 사실·성과·링크 유지. PDF 변경 없음.

Astro 오류·경고 없음. 정적 6페이지·122개 로컬 참조 검사 통과. 30개 브라우저 테스트 통과. 360/390/768/1440px overflow 검사의 대상을 네 상세 사례 전체로 확대. 모바일 도해 우선 배치 및 설명용 예시 회귀 검사 추가. JS 없이 읽기·키보드·동작 감소 및 200% 확대 기존 검사 유지.

기본 선 그림과 인물 그림은 정체성/구획을 위한 장식이며 접근성 트리에서 중복 정보를 만들지 않음. 사용자 이해의 근거는 별도의 설명용 도식·실제 화면·본문·PR 링크가 담당. 공개 배포 없음.
