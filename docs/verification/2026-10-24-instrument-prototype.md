# 전자기기·사용설명서 첫 화면 시안

사용자가 선택한 1번 컨셉의 첫 화면만 구현. 회색 본체, 어두운 표시창, 주황색 선택 키, 단색 사진과 작은 설명서 표기를 적용. 나머지 페이지의 레이아웃과 PDF는 변경하지 않음.

작업 선택은 브라우저 기본 radio와 CSS :has로 구현. 키보드 방향키·JS 없는 환경에서도 동작하며, 각 화면에서 실제 사례로 이동 가능. 도식은 작업 설명용 개념도. 수치·가상의 성과·장식용 실시간 상태 없음.

Astro 검사 및 정적 빌드/링크 검사 통과. 브라우저 31개 테스트 통과. 데스크톱과 390px 모바일에서 전환·줄바꿈을 직접 확인. 동작 감소 설정 지원. 공개 배포 없음.
