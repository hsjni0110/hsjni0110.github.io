# 대표 사례 요약과 상세 서사 정리

메인: 서비스 소개 한 문장, 구체적인 제목, 핵심 작업 두 문장, 시각 자료 하나와 상세 링크로 축소. 구현 범위·정성 반응·검증 한계·PR·AI 활용 설명은 기존 상세에서 유지. 기술 태그는 상세 제목 영역으로 이동. 모바일은 제목/설명 뒤에 그림을 배치하고 설명용 도식의 여백을 줄임.

상세: SpeakText는 인물 연결→검토/수정 도입→색 구분/일괄 수정→팀 반응→실제 사용자 검증 과제로 소제목 정리. ForgeSync는 기록 누락 분리와 가공 시간 판정을 별도 제목으로 분리하고 AI 개발 기준 설명을 검증·한계 앞에 배치. 문단 사실·출처·성과 범위 유지. 소제목의 동일 색 상자·번호 제거, 일반 제목과 구분선으로 전환. 일러스트·색상 유지.

Astro 검사 오류/경고 없음, 정적 빌드 및 120개 참조 검사 통과. 브라우저 30개 검사 통과. 데스크톱 메인과 모바일 메인/상세 직접 확인. 소제목 균형 줄바꿈 반영. PDF 내용은 이번 변경 없음. 공개 배포 없음.
