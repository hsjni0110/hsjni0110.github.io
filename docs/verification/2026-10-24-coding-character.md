# 캐릭터 루프·드로잉 설명·줄바꿈

사용자가 요청한 두 번째 캐릭터 스타일로 2×2 장면 시트 생성. 코딩 몰입→책상 두드림→해결에 놀람→다시 코딩, 같은 구도의 네 컷을 CSS로 12초 주기로 연결. GIF 파일 대신 최적화 WebP 시트(약 92KB) 사용. 일시정지/재생 제공, JS 없거나 동작 감소 설정이면 정지 화면. 터치/키보드 제어 지원. 큰 정면 얼굴은 제거.

원본 일러스트는 identity reference로만 사용하고 새로운 장면 PNG는 프로젝트 자산에 저장. 임시 모델·외부 리소스 추가 없이 Astro 이미지 최적화 사용.

링크: component의 각 열에 minmax(0,1fr), 링크/제목 min-width:0, 내부 텍스트 열 유연 너비 적용. 900px 이하는 한 줄에 하나씩 배치. 360/726/1100 너비에서 제목 영역 150px 이상 및 overflow 없음 검사.

참고: https://ncase.me/loopy/ (원·화살표로 관계 설명), https://ciechanow.ski/mechanical-watch/ (설명할 부분을 단계별로 분리). 이를 바탕으로 모플 경력에 기존 원본→임시 테이블→대상과 직접 적재 경로를 비교하는 짧은 드로잉 추가. 가짜 제품 UI나 측정 수치 없음.

Astro 검사 오류·경고 없음. 정적 6페이지·116개 참조 검사 통과. 32개 브라우저 테스트 통과, 200% 확대에서 도식 넘침을 수정하고 전체 재검증. 360px/726px/데스크톱 화면 직접 확인, 캡처 저장. 공개 배포 없음.
