# 일러스트 컨셉 전체 적용

첫 화면의 남색·청록·살구색을 공통 토큰에 적용. 경력 타임라인과 도해, 프로젝트의 내용별 SVG 선 그림과 색면, Writing의 노트 형태, 상세 제목의 도해와 번호형 소제목으로 구분. 장식 SVG는 aria-hidden 처리. 상세 사례 본문과 프로젝트·프로필 데이터, 외부 링크를 유지. 요약·공통 추상 제목·목차는 재도입하지 않음. PDF 변경 없음.

- Astro 검사 오류·경고 없음. 정적 6페이지·로컬 참조 122개·공개 PDF 일치 검사 통과.
- 브라우저 테스트 29개 통과: 키보드, JS 없는 읽기, 동작 감소, 360~1440px 너비 및 200% 확대 포함.
- 데스크톱 프로젝트/경력/상세와 모바일 상세/Writing 직접 확인. 상세의 모바일 도해를 제목 위로 옮겨 제목 너비 확보.
- 본문을 줄이거나 성과·수치를 새로 추가하지 않음. 공개 배포 없음.
