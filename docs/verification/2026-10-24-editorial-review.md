# 2026-10-24 포트폴리오 개편 검증

## 사용자 요청과 반영

- 첫 문장: ‘끝났다’는 말의 조건을 묻는 문장으로 호기심을 유도. 세 질문을 실제 사례·실무 영역의 앵커에 연결.
- 실무 경험을 대표 사례 앞으로 이동. 모플 설명은 실제 분석·구현·검증만 유지하며 전 과정 단독 수행 표현 재도입 없음.
- SpeakText·ForgeSync는 서비스 소개 → 판단 → 직접 기여 → 관찰 결과 → 근거의 순서. PR·판정 정책 코드·실제 화면 링크 제공.
- SpeakText 시각 자료는 판단 흐름 도식임을 명시. 발견된 적 없는 실제 UI 화면은 제작하지 않음.
- ForgeSync 기존 전후 화면을 native details로 비교. 데이터 정확도 개선 주장 없음.
- 개발 중 앱은 별도 짧은 영역, 실제 화면·모집 링크 없음. 새 버전 검증 전 유지.
- 교육·활동은 펼침 방식. 상세 본문은 유지하고 핵심 판단·구현 문장만 강조. 상세 요약·담당 블록·목차 재도입 없음.

## 디자인과 모션

밝은 종이색·청색 강조·큰 활자·번호·구분선으로 편집 리듬 구성. 스크롤 위치 표시, 현재 메뉴 표시, 단발성 reveal, 버튼 반응, 펼침 내용 진입 효과. 스크롤 제어·무한 반복·프레임워크 추가 없음.
JS 없이 본문과 링크는 읽을 수 있으며 비교·교육 펼침은 native details로 작동. 모션 줄이기 시 모든 새 효과 비활성화.

## 검증 결과

- 기본 경로: npm run verify, Astro 오류·경고·힌트 0, 28개 Chromium 검사 통과.
- /portfolio/ 하위 경로 및 HTTPS 가상 origin: 동일한 전체 검사 28개 통과. 실제 배포는 수행하지 않음.
- 마지막에 기본 로컬 환경으로 재빌드. 정적 7페이지·로컬 참조 129개·공개 PDF 동일성 및 공개 범위 검사 통과.
- 360·390·768·1440px 넘침 없음, 200% 확대·44px 메뉴·키보드·JS 없음·reduced motion·이미지 실패·직접 주소·PDF·폰트 검사 포함.
- 실제 브라우저: 데스크톱 첫 화면·대표 사례·전후 펼침, 390px 모바일 첫 화면·사례 확인. 중복된 앵커 여백 수정.
- 검증용 임시 뷰포트는 원복. PDF 본문은 변경하지 않음.
