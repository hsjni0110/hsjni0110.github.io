## 수정 원칙과 적용

- 새 슬로건을 만드는 대신 이름·백엔드 개발자·서비스 백엔드/데이터 파이프라인을 명시.
- 가상의 질문 세 개를 실제 작업 세 개로 교체: 모플의 배치 분석·분산 적재, SpeakText의 발화자 편집, ForgeSync의 기록 누락 분리.
- ‘제 작업은 이런 질문에서 시작됩니다’, ‘끝났다의 조건’, 작업 기록을 읽는 법을 설명하는 문단과 수사적 연락 제목 삭제.
- 첫 화면의 프로젝트 링크는 해당 사례로 이동. 사례에는 서비스 설명, 본인 구현 범위, PR/코드/실제 화면, 검증 범위를 유지.
- 폐기한 동시생활 앱은 메인·생성되는 상세 경로·관련 사례·공개 PDF에서 제외. 과거 초안은 공개 산출물 밖의 docs/content/archive에 보존.
- 새 게임은 공개 사례에 추가하지 않음.
- 기존의 키보드 탐색, 애니메이션 감소 설정, JS 없는 읽기, 접어서 비교하는 실제 화면은 유지.

## 아직 남는 한계

두 대표 프로젝트의 공개 사용자 성과는 확인되지 않음. SpeakText는 팀 내부의 정성적 피드백, ForgeSync는 공개 설비 1대의 하루 데이터 기반 구현. 디자인으로 이 한계를 감추거나 실사용 성과로 확대하지 않음. 다음 내용 보강은 새로운 수식어보다 실제 사용 결과나 공개 가능한 작업 증거가 필요.
