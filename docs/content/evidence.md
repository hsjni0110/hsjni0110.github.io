# 공개 콘텐츠 근거 장부

2026-10-18 인터뷰·원문·코드 조사에 근거한다. 전체 원칙과 상세 출처는 확정 설계 문서 6~8·13장에 있다. 이 문서는 정적 사이트 출력에 포함하지 않는다.
